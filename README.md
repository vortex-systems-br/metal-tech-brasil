# Metal Tech Brasil

Site oficial da **Metal Tech Brasil** – Serralheria e Coberturas Metálicas em Araçatuba/SP.

## Sobre o projeto

Site de alta conversão desenvolvido com foco em:

- Design moderno (preto + dourado)
- Mobile-first e responsivo
- Integração direta com WhatsApp
- Formulário inteligente de orçamento
- Galeria de trabalhos reais
- Schema.org LocalBusiness (SEO local)
- Open Graph para compartilhamento

## Como publicar

### Opção 1 – GitHub Pages
1. Crie um repositório no GitHub
2. Faça o upload desta pasta
3. Vá em **Settings → Pages**
4. Selecione a branch `main` e a pasta `/ (root)`
5. Pronto. O site estará no ar.

### Opção 2 – Netlify / Vercel
1. Arraste a pasta inteira no Netlify Drop ou conecte o repositório
2. O site sobe automaticamente
